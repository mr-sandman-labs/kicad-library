# **How to use this library**
Due to the current limitations of KiCAD (v10) this library is specifically
made to be used in a project.

No support for global use is panned.

Import symbol libraries manually:
|Nickname|Library Path|
| -- | -- |  
|passive_resistor|${KIPRJMOD}/library/symbol/passive/resistor.kicad_symdir|
|passive_oscillator|${KIPRJMOD}/library/symbol/passive/oscillator.kicad_symdir|
|passive_inductor|${KIPRJMOD}/library/symbol/passive/inductor.kicad_symdir|
|passive_capacitor|${KIPRJMOD}/library/symbol/passive/capacitor.kicad_symdir|
|ic_digital_mcu|${KIPRJMOD}/library/symbol/ic_digital/mcu.kicad_symdir|
|discrete_semiconductor_transistor|${KIPRJMOD}/library/symbol/discrete_semiconductor/transistor.kicad_symdir|
|discrete_semiconductor_mosfet|${KIPRJMOD}/library/symbol/discrete_semiconductor/mosfet.kicad_symdir|
|discrete_semiconductor_diode|${KIPRJMOD}/library/symbol/discrete_semiconductor/diode.kicad_symdir|
